# Calisthenics Phase 1 Tracker

Interactive 12-week Calisthenics Phase 1 Tracker web application.

## 🚀 Live Demo
Visit the live GitHub Page: **[https://adarshsandyal.github.io/calisthenics/](https://adarshsandyal.github.io/calisthenics/)**

## ✨ Features
- **12-Week Structured Program**: Push, Pull, Mixed, and optional Skill/Tendon days with built-in deload weeks.
- **Local Progress Saving**: Keeps track of completed sets in browser `localStorage`.
- **Prehab & Exercise Guides**: Expandable instructions for every movement.
- **Progress Tracking**: Real-time progress bars for overall and current week completion.
- **Responsive & Dark Mode**: Adapts seamlessly to mobile and desktop screens, respecting system dark mode preferences.
